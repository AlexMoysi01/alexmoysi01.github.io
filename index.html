Digit Recognition NN

Built a Java GUI for creating, loading, and saving networks, with a live visualization of the forward pass. Loaden

An autonomous assistant for construction and renovation sites, built by Argos Robotics. It follows workers and carries tools and materials, and is designed for uneven, stair-heavy sites. Built the depth-camera pathfinding for the Python MVP (shown), implementing a custom VFH+ (Vector Field Histogram+) obstacle-avoidance algorithm. Wrote single-pass computer vision kernels as Numba-compiled functions to minimize memory traffic, learning how memory bandwidth, not arithmetic, often limits performance. The next version, a larger tracked platform, is being rebuilt in Rust.

Python, Numba, Rust, VFH+, computer vision, depth camera, performance optimization

Mandelbrot Set Explorer

Interactive Mandelbrot and Julia set renderer built on my custom C++ OpenGL engine, created to drive the engine's development and design its wrapper API abstractions. Renders in selectable modes: 32-bit or 64-bit floating point, on the GPU (GLSL shaders) or on the CPU using multithreaded AVX intrinsics. Built to benchmark CPU double-precision throughput against consumer GPUs, whose FP64 rate is as low as 1/64 of their FP32 rate, making vectorized CPU code competitive at high precision. Renders at 4x supersampled anti-aliasing (SSAA) at native resolution into application subwindows, and applies normal-map-based shading for depth and lighting.

OpenGL, C++, GLSL, AVX/SIMD intrinsics, Multithreading, Git
